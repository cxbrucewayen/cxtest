# 贪吃蛇游戏 (Snake Game)

一个功能完整的贪吃蛇网页游戏，可直接部署到腾讯云服务器。

## 🎮 游戏特点

- 🐍 经典贪吃蛇玩法
- 🎨 精美的渐变UI设计
- 📱 支持PC和移动端
- ⌨️ 键盘控制（方向键/WASD）
- 👆 触摸控制（移动设备滑动）
- 💾 自动保存最高分
- ⚡ 游戏速度随分数递增
- 🎯 完全离线可用（单HTML文件）

## 📁 项目文件

- `snake_game.html` - 完整的游戏文件（可直接在浏览器打开）
- `DEPLOYMENT.md` - 详细的腾讯云部署指南
- `README.md` - 本文件

## 🚀 快速开始

### 本地运行

1. 直接在浏览器中打开 `snake_game.html` 文件
2. 点击"开始游戏"按钮
3. 使用方向键或WASD控制蛇的移动

### 在线部署

查看 `DEPLOYMENT.md` 文件，获取详细的腾讯云部署教程，包括：
- 腾讯云对象存储（COS）部署方案 ⭐ 推荐
- 腾讯云服务器（CVM）部署方案
- 腾讯云Serverless（SCF）部署方案

## 🎯 游戏说明

- 使用方向键 ⬆️⬇️⬅️➡️ 或 WASD 控制蛇的移动
- 吃到红色食物可以增加分数和长度
- 避免撞到墙壁和自己的身体
- 游戏速度会随着分数增加而加快
- 按空格键可以暂停/继续游戏

## 🛠️ 技术栈

- HTML5 Canvas
- CSS3（渐变、动画、响应式设计）
- 原生JavaScript（无依赖）
- LocalStorage（保存最高分）
